# BAREEQ AL AQEEQ — Angular website

Luxury interior atelier website starter built with Angular 17.

## Run locally
- Install Node.js 20 or newer.
- Run `npm install`
- Run `npm start`
- Build for deployment with `npm run build`

Production build output: `dist/bareeq/browser`

## Zoho Catalyst
This repository contains the Angular source. Build the app and deploy the generated browser output using the Catalyst web client hosting workflow or Catalyst CLI. The booking form is currently a front-end preview and is not connected to email, CRM, or a database.
